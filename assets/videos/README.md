# Локальные видео Viper

Добавь в эту папку три MP4-файла со следующими именами:

- `viper_ability_1.mp4`
- `viper_ability_2.mp4`
- `viper_ability_3.mp4`

Карточки на главном экране уже настроены на эти пути. Видео будут воспроизводиться локально через пакет `video_player`.

Если у тебя уже есть ролики с другими именами, поменяй значения `videoPath` в `lib/pages/home_pages.dart`.
