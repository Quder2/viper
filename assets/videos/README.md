# Локальные видео Viper

В папке используются четыре MP4-файла:

- `viper_ability_C.mp4` — Змеиный укус
- `viper_ability_Q.mp4` — Ядовитое облако
- `viper_ability_E.mp4` — Токсичная завеса
- `viper_ability_ult.mp4` — Гнездо гадюки

Имена и пути синхронизированы с карточками на главном экране в `lib/pages/home_pages.dart`. Видео воспроизводятся локально через пакет `video_player`.
