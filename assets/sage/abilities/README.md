# Sage ability icons

The app expects these local PNG files:

- `barrier_orb.png` — C / Barrier Orb
- `slow_orb.png` — Q / Slow Orb
- `healing_orb.png` — E / Healing Orb
- `resurrection.png` — X / Resurrection

Run `tools/download_sage_assets.ps1` from the repository root to download the ability icons and profile artwork into their folders. The script uses the Sage game-asset endpoints and keeps the original icon files (no recoloring or redrawing).
