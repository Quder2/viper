# Sage assets

All Sage-specific media lives under this directory. Keep this structure when adding files:

- `abilities/` — ability icons
- `images/` — portrait, background and preview artwork
- `videos/` — local MP4 ability recordings
- `voice/` — Russian voice lines (MP3)

File names are documented in the README inside each folder. Shared Flutter widgets stay in `lib/widgets/`; only agent media belongs here.
